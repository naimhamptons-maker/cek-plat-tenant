🔄 Sync Otomatis dengan Google Sheets

Tempelkan link Google Sheets Anda di bawah ini. Aplikasi akan otomatis mengonversi link menjadi format CSV/JSON dan menyinkronkan data ke memori lokal HP/PC secara berkala saat online — dan tetap bisa digunakan 100% offline saat internet mati.

Agar Google Sheet bisa ditarik otomatis tanpa hambatan CORS:
1. Di Google Sheets, klik Share (Bagikan) → ubah akses menjadi Anyone with the link (Viewer), ATAU
2. Klik File → Share → Publish to web → pilih sheet TOWER A dan format CSV, lalu tempel link-nya di atas.
